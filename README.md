# File Search Engine (Python)

## Overview

This is a simple Python-based File Search Engine that helps users search for files by entering a keyword. The program scans the selected folder and its subfolders, then displays matching file names along with their file paths and sizes.

## Features

* Search files using a keyword
* Scan folders and subfolders automatically
* Display complete file paths
* Show file sizes in B, KB, or MB
* Measure and display search time

## Technologies Used

* Python
* os module
* time module

## How It Works

1. The user enters a folder path.
2. The user enters a keyword to search.
3. The program scans all files inside the folder and its subfolders.
4. Matching files are displayed with:

   * File path
   * File size
5. Total matching files and search time are shown.

## How to Run

1. Download or clone this repository.
2. Open the project in Python.
3. Run the program:

   ```bash
   python file_search_engine.py
   ```
4. Enter the folder path and keyword when prompted.
